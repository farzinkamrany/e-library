# 📚 Book Library App

یک اپلیکیشن وب مدرن برای نمایش، جستجو و مدیریت کتاب‌ها. کاربران می‌توانند کتاب‌ها را جستجو کنند، دسته‌بندی‌ها را مرور کنند، کتاب‌های مشابه ببینند، و علاقه‌مندی‌های خود را مدیریت کنند.  

---

## ✨ ویژگی‌ها

- جستجوی سریع کتاب‌ها با تایپ زنده
- دسته‌بندی کتاب‌ها بر اساس موضوع
- مشاهده جزئیات هر کتاب شامل توضیحات، نویسنده و رتبه‌بندی
- مدیریت علاقه‌مندی‌ها با ذخیره در **LocalStorage**
- مشاهده کتاب‌های مشابه در همان دسته‌بندی
- قابلیت اشتراک‌گذاری لینک کتاب
- طراحی مدرن و ریسپانسیو با Tailwind CSS
- تجربه کاربری روان و انیمیشن‌های جذاب

---

## 🛠️ تکنولوژی‌ها

- **React** + TypeScript
- **Zustand** برای مدیریت استیت
- **React Router** برای روتینگ
- **Tailwind CSS** برای طراحی واکنش‌گرا
- **MUI Icons** برای آیکون‌ها
