# پروژه E-Library Front-End

این پروژه یک **کتابخانه فرانت‌اند حرفه‌ای** است که با **React + TypeScript + Tailwind CSS** ساخته شده است.

## ویژگی‌ها
- نمایش کتاب‌ها با جستجو و فیلتر دسته‌بندی
- صفحه جزئیات کتاب
- ریسپانسیو و مدرن
- مدیریت وضعیت با Zustand
- داده‌ها فیک و داخلی

## نصب و اجرا
```bash
npm install
npm start
# یا yarn install && yarn start
